# TimeWiseHub

Cloud-based productivity platform for time tracking, expense management, project work, and team insights.

[![CI](https://github.com/Vividex/TimeWiseHub/actions/workflows/ci.yml/badge.svg)](https://github.com/Vividex/TimeWiseHub/actions/workflows/ci.yml)

Live URL: https://timewisehub.vercel.app

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Supabase
- Stripe
- Vercel
